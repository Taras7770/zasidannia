# Мої засідання

Особистий календар судових засідань для Android і macOS.

- Джерело даних: ДСА України, набір «Список справ призначених до розгляду» на [data.gov.ua](https://data.gov.ua/dataset/3a321301-a06f-487b-9d19-e6b917250aee), ліцензія CC BY.
- Завдання GitHub Actions щоночі завантажує набір, ділить його на частини за кодом суду і будує індекс учасників.
- Застосунок (`web/`) читає лише потрібні частини. Пошук працює за номером справи та за учасником або представником.
- Список справ користувача цей репозиторій не містить. Список зберігається на пристрої і в окремому приватному репозиторії.

## Склад

- `web/` : застосунок (один інтерфейс для телефона і компʼютера).
- `scripts/build-data.mjs` : побудова даних.
- `android-shell/` : оболонка Android (Capacitor) з локальними нагадуваннями.
- `test/` : перевірки.
